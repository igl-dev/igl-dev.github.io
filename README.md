# IGL Demo 🎮🚀 <br />
This is a React application built with Vite, using SCSS for styling and AOS for animations.  

🌍 Live Demo <br />
🔗 IGL Demo# React + Vite <br />

# 📌 Features <br />
✅ Fast performance with Vite <br />
✅ Modern UI with SCSS <br />
✅ Smooth animations using AOS <br />
✅ Social links with React Icons <br />
✅ Deployable on GitHub Pages <br />

# 🚀 Getting Started <br />
## 🔧 Installation <br />
> 1. Clone the repository <br />

` git clone https://github.com/igl-dev/igl_demo.git ` <br /> 
` cd igl_demo ` <br /> 

> 2. Install dependencies <br />

` npm install ` <br /> 

> 3. Start the development server <br />

` npm run dev ` <br />

Open http://localhost:5173 in your browser. <br />
